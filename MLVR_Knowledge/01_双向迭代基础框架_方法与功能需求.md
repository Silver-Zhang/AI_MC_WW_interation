# 双向迭代基础框架：方法与功能需求

> 本文档定义第一版 RMC 双向迭代权重窗框架“方法需要什么”。
> 当前阶段只冻结算法流程、功能需求、数据语义和边界，不提前规定 C++ 类、文件、具体接口形式或高级机器学习实现。

## 1. 方法目标

构建一个与具体场重构方法无关的 Forward–Adjoint 双向迭代 Weight Window（WW）基础框架，用于深穿透 Monte Carlo 问题的自适应减方差。

第一版优先完成 RMC 侧基础闭环，不直接绑定 DNN、PINN、GNN、FNO 等高级机器学习算法。

正式双向迭代的基本闭环为：

```text
WW_A(k)
  ↓
Adjoint MC
  ↓
Adjoint field + RE
  ↓
Field Reconstruction
  ↓
WW_F(k)
  ↓
Forward MC
  ↓
Forward field + RE
  ↓
Field Reconstruction
  ↓
WW_A(k+1)
```

其中：

- `WW_A(k)`：第 k 轮伴随输运使用的权重窗；
- `WW_F(k)`：第 k 轮正向输运使用的权重窗；
- Field Reconstruction：场处理/场重构黑箱，第一版不绑定具体算法。

---

## 2. 第一版总体流程

### 2.1 Bootstrap Stage：正式迭代前初始化

正式双向迭代开始前，先执行一次独立的 Bootstrap Stage，用于生成第一轮伴随权重窗 `WW_A(1)`。

第一版 Bootstrap 默认采用真实物理问题下的低粒子数 Analog Forward MC：

```text
Analog Forward MC
  ↓
Bootstrap forward field + RE
  ↓
Field Reconstruction
  ↓
WW_A(1)
```

第一版不使用权重窗、不修改材料密度、不构造辅助物理问题。

Bootstrap 的唯一正式目标是为第一次 Adjoint MC 提供 `WW_A(1)`；Bootstrap 不属于正式 iteration 编号。

后续可扩展其他 Bootstrap 策略，例如降密度辅助问题、其他减方差方法、外部粗略场或多阶段初始化，但第一版只保留策略可扩展性，不设计这些扩展的具体实现。

### 2.2 正式双向迭代

正式 iteration 从 `k = 1` 开始。

#### Step A：Adjoint MC

输入：

- 基于目标响应定义的 Adjoint source；
- `WW_A(k)`。

输出：

- Adjoint 空间–能群场；
- 对应统计误差 RE。

#### Step B：Adjoint Field Reconstruction

输入：

- Adjoint field；
- Adjoint field RE。

输出：

- 重构后的 Adjoint field。

#### Step C：生成 Forward WW

由重构后的 Adjoint field 生成：

- `WW_F(k)`。

#### Step D：Forward MC

输入：

- 真实正向源；
- `WW_F(k)`。

输出：

- 目标响应及其统计误差；
- Forward 空间–能群场；
- Forward field RE；
- 用于评价当前 Forward WW 的计算统计信息。

#### Step E：Forward Field Reconstruction

输入：

- Forward field；
- Forward field RE。

输出：

- 重构后的 Forward field。

#### Step F：生成下一轮 Adjoint WW

由重构后的 Forward field 生成：

- `WW_A(k+1)`。

随后进入下一轮迭代。

## 3. Field 数据定义

### 3.1 第一版 Field 的物理维度

第一版 Field 只考虑：

- 空间网格；
- 能群。

即 Field 的基本索引为：

```text
Field[group][mesh]
```

第一版不包含：

- 角度变量；
- 时间变量；
- 高阶角通量矩；
- 跨 iteration 历史数据；
- 神经网络特征；
- 材料/几何辅助特征。

材料、几何、距离等信息如果未来 Field Reconstruction 需要，应作为重构算法的辅助输入，而不是定义为 MC Field 本身。

### 3.2 Field 必须包含统计误差

每个空间–能群位置至少包含：

```text
mean field value
relative error (RE)
```

因此第一版 MC Field 的语义为：

```text
Statistical Field = Mean Field + Relative Error
```

RE 在当前阶段只定义为“RMC tally 统计体系给出的该空间–能群估计量相对统计误差”。

Stage 1 不提前规定其内部 batch 划分、方差累计公式或 RMC 中具体实现方式；这些内容在 RMC 功能审查阶段根据源码确认。

### 3.3 Forward 与 Adjoint Field

Forward 和 Adjoint Field 采用统一的数据维度和基本统计信息：

```text
Forward Field  = {forward mean field, forward RE}
Adjoint Field  = {adjoint mean field, adjoint RE}
```

二者的数据规范应尽可能统一，但物理语义和生命周期必须严格区分。

当前阶段不决定未来 C++ 中是否采用同一个数据结构或通过何种 metadata 区分；该问题留到接口设计阶段。

## 4. Bootstrap Stage 功能需求

### 4.1 Bootstrap 输入

第一版 Bootstrap 使用真实正向物理问题：

- 真实 Forward source；
- 真实 geometry/material definition；
- 与正式迭代一致的能群结构；
- 与正式迭代一致的 Field mesh。

### 4.2 Bootstrap 输出

Bootstrap 必须产生：

```text
Bootstrap Forward Field
Bootstrap Forward RE
```

经过 Field Reconstruction 后，最终生成：

```text
WW_A(1)
```

### 4.3 Bootstrap 数据边界

Bootstrap 不属于正式 iteration，因此第一版中：

- 不参与正式 iteration 编号；
- 不参与正式 Forward WW 的 FOM 比较；
- 不进入跨 iteration 历史场累计；
- 不作为最终物理结果；
- Bootstrap field 和 RE 可保留用于诊断、可追溯性和后续方法研究。

### 4.4 Bootstrap 与正式迭代的网格/能群一致性

第一版要求：

```text
Bootstrap field mesh = Iteration field mesh
Bootstrap energy groups = Iteration energy groups
```

第一版不引入额外 mesh mapping 或 energy-group mapping。

### 4.5 Bootstrap 后续可扩展性

第一版默认策略：

```text
Low-particle Analog Forward Bootstrap
```

后续可以研究：

- reduced-density Bootstrap；
- auxiliary variance-reduction Bootstrap；
- external-field Bootstrap；
- multi-stage Bootstrap。

这些属于后续优化方向，不进入第一版实现范围。

## 5. 功能需求分解

### F01 — Forward fixed-source MC

RMC 能够执行真实源驱动的固定源正向 Monte Carlo 输运。

第一版 Bootstrap 和正式 Forward iteration 均依赖该能力。

### F02 — 多群 Adjoint transport

RMC 能够执行本框架需要的多群伴随输运。

后续功能审查重点确认伴随输运物理实现及实际可用状态。

### F03 — Adjoint source

能够根据目标响应定义并执行第一版所需的伴随源。

### F04 — Adjoint transport + Weight Window

不仅要求 Adjoint transport 和 WW 单独存在，还要求二者能够正确组合使用。

这是 Stage 2 需要重点审查的组合功能之一。

### F05 — Forward spatial-energy field tally

Forward MC 能够输出与 Field Reconstruction 需要一致的空间–能群 Field。

Bootstrap 和正式 Forward iteration 均需要该能力。

### F06 — Adjoint spatial-energy field tally

Adjoint MC 能够输出对应的空间–能群 Adjoint Field。

### F07 — Field statistical uncertainty / RE

Forward 与 Adjoint Field 均能够获得与每个空间–能群位置对应的统计误差信息 RE。

### F08 — Weight Window 输入与应用

框架能够把给定的空间–能量 WW 用于实际粒子输运，包括 RMC 已有 splitting / Russian roulette 机制所需的数据链路。

第一版不要求先确定 WW 由哪个算法生成，只要求生成后的 WW 能进入输运。

### F09 — Response statistics and FOM

正式 Forward iteration 能够得到目标响应和对应统计误差，并保留评价 Forward WW 效率所需的计算信息。

FOM 用于后续评价 Forward WW；Bootstrap 不参与该评价。

### F10 — Field Reconstruction 边界

框架必须存在从 Statistical Field 到完整重构场的独立处理边界：

```text
Statistical Field
  ↓
Field Reconstruction
  ↓
Reconstructed Field
```

第一版不绑定具体算法，后续可以从简单回归/插值方法开始，再扩展到机器学习方法。

### F11 — 固定次数的双向迭代调度

第一版只要求用户给定固定迭代次数 `K`，框架依次执行：

```text
Bootstrap
  ↓
Iteration 1: Adjoint → Forward
  ↓
Iteration 2: Adjoint → Forward
  ↓
...
  ↓
Iteration K: Adjoint → Forward
```

第一版不实现自动 RE/FOM 收敛停止、patience、WW change criterion 或其他自适应终止策略。

---

## 6. 第一版当前边界

第一版明确不包含：

- 连续能量 Adjoint transport；
- DNN / PINN / GNN / FNO 等高级场重构方法；
- 跨 iteration 历史 Field 累计；
- 自动超参数优化；
- 自适应 iteration termination；
- Bootstrap 降密度等高级初始化策略；
- 不同 Bootstrap / iteration mesh 或能群之间的数据映射。

---

## 7. Stage 1 当前冻结结论

1. 第一版采用多群 Adjoint transport。
2. Field 定义为“空间网格 × 能群”的统计场，至少包含 mean field + RE。
3. Forward 与 Adjoint Field 数据规范统一，但物理语义严格区分。
4. 第一版不进行跨 iteration 历史场累计。
5. 第一版使用固定 iteration 次数，不做自动收敛停止。
6. 正式双向迭代前增加独立 Bootstrap Stage。
7. 第一版 Bootstrap 采用真实物理问题下的低粒子数 Analog Forward MC。
8. Bootstrap 的正式目标是生成 `WW_A(1)`，其数据不参与正式 FOM 或最终物理结果。
9. Bootstrap 与正式迭代使用相同 Field mesh 和能群结构。
10. Field Reconstruction 保持方法无关，第一版不绑定高级机器学习算法。

## 8. 与后续 Stage 的边界

本文档回答：

> 为实现第一版双向迭代 WW 基础框架，方法和软件需要具备哪些能力？

本文档不回答：

- RMC 当前是否已经具备这些能力；
- 某功能具体位于哪个源码文件；
- 某功能当前是否正确；
- 功能之间具体采用什么代码接口；
- 应新增哪些类、函数或文件。

这些问题分别留给 Stage 2（RMC 功能审查）及后续接口设计阶段。
