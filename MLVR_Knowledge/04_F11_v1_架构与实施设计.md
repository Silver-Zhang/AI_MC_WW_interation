## 1. 总体决定

**F11 是现有 RMC 固定源能力的扩展：RMC 一次启动，在内部完成固定 K 轮正向—伴随交替计算；外部程序只处理统计场并返回下一张权窗。**

不建立平行的 `src/MLVR/` 子系统，不引入新的输运引擎或通用 Session/Manager 类，不复制现有粒子输运循环。允许在 `src/` 根目录增加确有独立职责的少量实现文件，仍实现现有类的方法。

### 1.1 内外分工

| 职责 | RMC 内部 | 外部程序 |
|---|---|---|
| 模型、材料、MGACE | 读取一次并保留 | 不参与 |
| K、Bootstrap、伴随/正向执行顺序 | 管理并执行 | 不改变 |
| 真实源、TARGET、简单伴随源 | 定义、构造和抽样 | 不改变 |
| 每次计算的 NPS、随机数、批次 | 管理并执行 | 不参与 |
| 统计清零、角色切换、缓存重建 | 执行并检查 | 不参与 |
| Field、RE、目标响应、FOM | 按固定口径计算、输出 | 只消费数据 |
| 场重构/补全 | 不实现具体方法 | 负责 |
| 重构场到 WW lower 的映射 | 不规定具体研究公式 | 负责 |
| 权窗文件、网格/能群检查、实际应用 | 读取、验证、安装、执行原分裂/轮盘 | 输出合法 lower |
| 每轮文件及身份 | 建目录、命名、保存 | 在指定目录保存重构结果及算法记录 |

外部程序内部仍分“场重构”和“权窗映射”两个步骤，不能因为只有一个可执行文件，就把两者的数据合同混成一件事。

### 1.2 本版范围

standard ASCII MGACE（`ais=OFF`）、中子固定源、Linux 串行（MPI/OpenMP 均关闭）、有限 Cartesian 网格、Type=1 track-length tally、`Energy=-1`、`Normalize=1`、单套 native track-mesh WW。

几何、材料、基础核数据、场网格、能群和 WWP 在一次 F11 计算中不变。每次仅改变角色、工作源、源历史数、随机数段和权窗数值。

起始源粒子权重限制为 1；不得把输运中正常变化的权重误当作不满足这一限制。非零裂变产生项须通过生产 F→A→F→A 验证后才开放；此前首个可交付版本明确限定非裂变范围，而不是偷偷关闭裂变后把原问题当作已支持。

暂不加入跨 iteration 统计合并、每批独立场、自动收敛、best-anchor 更新、自动成品计算、连续能量、耦合粒子、并行持久执行、任意响应、多网格映射或断点恢复。它们是后续任务，不应以论文曾包含为由重新塞回本版。

## 2. 两份方案的合并取舍

| 议题 | 本版采用的决定 | 说明 |
|---|---|---|
| 迭代执行位置 | `CDCalMode::CalcMLVR()` | 两稿一致；一次 `RunCalculation()` 内完成全部计算 |
| MLVR 配置保存位置 | `CDCalMode` 持有一个小的 `MLVRConfig` 值成员 | 采用 Task 16；配置不拥有模型、tally 或粒子库 |
| 固定源可重复执行 | 抽出唯一输运核心，普通入口保留 | 两稿共识；不复制 Task 13 的跳初始化 token |
| 每轮清理 | 调度层组织，具体对象清理自己的数据 | 不把所有字段直接赋值集中在 `CalcMLVR.cpp` |
| WW 网格 | 从选定 Field tally 的完整网格构建 | 采用 Task 15；不用用户再输入一张静态 WWMESH |
| NPS/seed | MLVR 为唯一明确配置来源 | 拒绝重复显式 POPULATION/SEED，不要求写两份相同数值 |
| Field 文件 | 保持逻辑和文件数据集均为 `[Nspace,G]` | 保留用户已接受的 F10 形状；不采用 Task 15 的一维文件加四维 shape 草案 |
| Bootstrap iteration | `none`，与正式迭代分开 | 不把 Task 15 的 0 当成正式 iteration 0 |
| TARGET 群编号 | 输入卡为从低到高的一基物理群编号；文件为零基 | 不把同一个 GROUP 关键字悄悄改成 MeV 区间；输出解析后的真实能量范围 |
| Field 数值 | 明确转换成体积平均、群积分通量 | 不能无条件照抄 Ave；体积问题须动态验收 |
| 响应 RE | 每个完整源历史先合成目标分数，再累计平方 | 采用 Task 15，不能从最终各 bin 的 RE 拼接 |
| 输出句柄 | 普通 RMC 输出保持进程级；新增逐次输出使用局部句柄 | 采用 Task 15，避免每半轮调用整个 OutputEnding |
| 外部命令 | 可执行文件路径 + 固定参数，不经 shell 拼接 | 必要 Python/参数放进用户自己的可执行启动脚本 |
| 原有格式化输入输出 | 首版不承诺完整 `.FMTinp` 可复跑 | 保留原输入/包含文件及解析结果；不能只加 MLVR 行就声称完整 round trip |

这些是本次统一设计选择，不是声称另一种配置归属或文件划分在技术上不可能。

## 3. 代码开发结构

### 3.1 现有类的职责

下面的新方法名为设计名称，实际命名可按 RMC 风格调整，但职责不得改变。

| 现有类/文件 | 扩展内容 | 不应承担的内容 |
|---|---|---|
| `CDInput` / `ReadInputBlocks.cpp` | MLVR 块识别、解析、显式出现标记、跨卡检查 | 不运行输运或重构 |
| `CDCalMode` / `RunCalculation.cpp` | 持有 MLVR 配置；固定源模式中分派普通/F11 路径 | 不复制模型、tally、WW |
| `CDCalMode::CalcMLVR` | Bootstrap/K 轮调度、半轮准备顺序、外部调用、失败传播 | 不写粒子碰撞/统计公式 |
| `CDFixedSource` | `ResetRunState`；NPS、完成数、批次、粒子库、归一化状态 | 不拥有重构模型 |
| `CDAceData` | 双向角色设置；清理/重建伴随派生量；提供完整物理群边界 | 不重读 raw MGACE 来冒充 reset |
| `CDParticleState` | 有明确覆盖清单的瞬态/截面缓存重置和重建 | 不做包含旧指针/缓存的盲目浅拷贝 |
| `CDExternalSource` | 从 TARGET 建立普通源定义；准备干净的工作源 | 不新增另一套粒子抽样内核 |
| `CDTally` / `CDTallyData` | 保留定义，清本轮统计；目标 history score；Field 转换和导出 | 不负责 WW 映射或外部训练 |
| `CDWeightWindow` | 从 Field 建拓扑；校验/接收 lower；复用 `ProcessWeightWindow` | 不接管研究性映射公式 |
| `CDOutput` / Timer | 整次运行摘要、独立逐次摘要、各段时间 | 不在换轮时关闭全部进程级资源 |
| 实际传入的 `CDRNG` | 明确的随机数段配置与记录 | 不按同名变量猜测 owner |

源码依据：`RunCalculation.cpp:6-13,83-89`；`CalcFixedSource.cpp:67-749`；`Tally.h:1025-1030`；`TallyData.cpp:17-99`；`WeightWindows.cpp:45-101`。`main.cpp` 同时有全局和局部同名 ORNG，应跟踪实际引用，不能操作错对象。

### 3.2 新增文件

首版计划增加以下根目录文件，不设独立子目录：

```text
src/MLVRConfig.h
src/ReadMLVRBlock.cpp
src/CalcMLVR.cpp
src/BuildMLVRAdjointSource.cpp
src/OutputMLVRField.cpp
src/ReadMLVRWeightWindow.cpp
```

`MLVRConfig.h` 仅放共享的小数据定义，如配置、解析后的 TARGET 和运行身份，不引入管理器、模型所有权或复杂继承。

外部进程调用若已足够长或需要独立测试，可再增加 `src/MLVRExternal.cpp`；每轮准备的协调实现也可移到单独 cpp，但不因此新建“大而全”的准备类。文件数量不是验收指标：既不为了漂亮无限拆，也不为了少建文件把平台调用塞进输运循环。

### 3.3 CalcFixedSource 的拆分

按当前归档基线，建议划分：

- 原 76–95 行：完整初始化与相应粒子准备，抽成 `InitializeFixedSourceModel`。
- 原 97–719 行：保留唯一 `ExecuteFixedSourceRun`，包括原 batch/history/后代处理与负载平衡结束逻辑。
- 原 721 行起：统计收尾与普通输出拆开；`ProcessTally` 每次最终执行一次。
- 普通 `CalcFixedSource` 保留包装入口、原计时范围、原可选模块和输出次序；本版没有启用的旧粒子路径不能删除。

```text
普通固定源：
CalcFixedSource
  → 原完整初始化
  → 唯一 ExecuteFixedSourceRun
  → ProcessTally + 原普通输出/可选收尾

F11：
CalcMLVR
  → 一次完整初始化
  → 每次：Prepare → ExecuteFixedSourceRun → Finalize → 交换文件
```

`ExecuteFixedSourceRun` 不再调用完整初始化或进程级收尾；统计结束由明确的 `FinalizeFixedSourceRun` 负责，禁止在 core、caller、Field writer 中重复调用 `ProcessTally`。

原 `RunCalculation` 的按值/引用接口不为 F11 全面重构。F11 内部持续引用本次调用中实际参与计算的模型和 tally；初始化之后不再复制这些对象。普通 `CalcFixedSource` 原按值 source 的语义也应保留：给新核心传引用时，引用其本次调用的工作副本，不把源的局部修改泄露回原定义。

## 4. 完整执行流程

```text
读取输入一次
→ 检查 MLVR 与旧卡的冲突
→ 以 Bootstrap 的正向/无 WW 状态初始化模型一次
→ 解析完整网格、MG 边界、TARGET 和随机数计划
→ 建立并保存真实源定义、伴随源定义
→ 建立 WW 网格，但不启用 WW

Bootstrap：
    Prepare(Forward, N_B, physical_source, WW=OFF)
    Execute
    Finalize
    写 Field
    外部重构/映射
    校验并保存 WW_A(1)

for k = 1 ... K:
    Prepare(Adjoint, N_A, adjoint_source, WW_A(k))
    Execute
    Finalize
    写 Field
    外部重构/映射
    校验并保存 WW_F(k)

    Prepare(Forward, N_F, physical_source, WW_F(k))
    Execute
    Finalize Field + target response + RE + FOM
    写 Field / 本轮摘要
    外部重构/映射
    校验并保存 WW_A(k+1)

汇总全部运行与 WW
→ 整个 RMC 正常收尾一次
```

正式一轮是 A+F。共 `2K+1` 次 MC 计算和 `2K+1` 次外部调用。K=3 对应 7 次 MC 与 7 次外部调用。

最后 `WW_A(K+1)` 仍生成、校验和保存，但不继续执行 A(K+1)，标记 `used=false`。保留它不等于已经实现断点续算；真正续算还涉及随机数、状态和配置恢复，后续另做。

Bootstrap 指“无权窗的正向启动计算”。不因此自动关闭 RMC 原有隐式俘获等机制，不把它误标成严格全模拟法。

同一次 MC 从开始到结束，其 source、角色和 WW 固定；只能在完整 MC 计算之间交换新权窗。

## 5. 每次运行的准备与对象生命周期

### 5.1 四类数据

| 类别 | 内容 | 每次的处理 |
|---|---|---|
| 保留 | 几何、材料基础定义、raw MGACE、场/群定义、tally 登记、WW 几何/能群/WWP、原始源定义 | 保持地址/定义有效，不重读、不重复登记 |
| 清零 | 完成数、finish、源历史计数、bank、源统计、归一化量、Score/ScoreTemp/Sum1/Sum2/Ave/RE、相关 Sum3、touched/index 集合、启用的统计诊断 | owner 自己清；不只调用当前 SetZero 就结束 |
| 设置 | 本次角色、N、工作源、seed/stride/位置、WW 身份、运行编号 | 来源唯一，写入实际参与输运的对象 |
| 重建 | 伴随派生截面、物理能量/内部群截止、粒子临时/截面缓存、WW 上界/存活权重 | 根据本次配置建立，不能保留上轮错误值 |

### 5.2 准备顺序

1. 确认上一计算已经统计结束，所有真实后代均已处理，无未关闭的交换文件。
2. 清除本轮计数、bank 和统计数据；保留 tally 定义及登记关系。正确处理 bank 的原有哨兵，不把“允许一个哨兵”误判为残留粒子。
3. 设置 NPS 并重新计算现有粒子区间；选择由不可变源定义生成的干净工作源。
4. 显式设置 FixedSource 与 AceData 的 A/F 标志。
5. A：从零重建伴随散射/裂变派生量；F：明确清理/不用伴随派生量。raw 数据始终不变。
6. 重置粒子临时状态，复用现有几何/材料/核素缓存准备部件，最后明确设置 particle role，确保三层一致。
7. 从保留的物理能量定义重新得到运行截止，不能把上次内部群号再次当 MeV。第一版不引入新的研究性截止策略，必须与 fresh 对照的物理范围一致。
8. 配置本次随机数段。安装已经完整校验的 WW lower，并经原函数生成 upper/survival；Bootstrap 显式保持 WW 关闭。
9. 检查零统计、有效 N、合法源、角色一致、数组尺寸、WW 身份和随机数状态，之后才进入第一条 history。

生产实现必须使用 owner 内的方法，而不是照搬实验 driver 的 friend 访问、placement-new 和外部逐字段强改。粒子状态可以显式重置或在局部安全构造新的瞬态对象，但必须保证引用/缓存生命周期清楚且不复制整个模型。

### 5.3 随机数

只给用户一个根种子。首版采用已做重复运行验证的 RNG 类型，初始建议 Type=2；STRIDE 复用现有配置。由运行顺序及累计源历史数划分不重复的随机数段，并记录每次可独立复现的有效 seed/stride/offset。

不能以“种子不同”替代随机数段检查；检查累计步数、乘法和周期溢出，以及单条源历史（包括全部后代）是否超出 STRIDE。超出时不得继续宣称随机数段互不重叠。保持原 RNG 算法，不另造生成器。

## 6. TARGET、伴随源与响应统计

### 6.1 唯一物理定义

本版 TARGET 是：**所选空间区域的体积平均、所选能群的积分通量之和。**

设空间集合为 I，能群集合为 J，网格体积为 V_i，目标总体积 V_T=Σ_i∈I V_i，φ_i,g 是体积平均且已按能群积分的通量，则

\[
R=\frac{1}{V_T}\sum_{i\in I}V_i\sum_{g\in J}\phi_{i,g}.
\]

空间按体积平均，群求和，不再除以群数，也不乘 ΔE。一个解析后的 TARGET 同时用于正向响应和伴随源，不允许两套独立定义。

选择区间重叠时先取并集，不能重复计权。首版不提供任意 response weight、剂量、反应率或表面响应。

### 6.2 伴随源

令 m=|J|。对应的单位起始源抽样概率为

\[
p(i,g)=\frac{V_i}{V_Tm}.
\]

按体积抽空间 bin，bin 内均匀；选定群等概率；方向各向同性；起始权重为 1。

复用 `CDExternalSource`、`CDSource`、现有区间分布和离散能量分布：每个选中空间 bin 建一个普通源组件，所有组件共享所选群中心的离散谱，不必为每个 bin×group 建一套完整源对象。能量传物理群中心，再由原 `SampleFixSource` 转成内部群号；不新建伴随专用抽样内核。

源定义不随迭代改变，首轮构造后保留；每次使用干净工作副本。真实正向源与伴随源分别保存，切换不会覆盖真实源定义。

TARGET 必须表示有效输运域内的完整选定网格体积。不能暗中丢弃无效源点或把网格体积改成材料交集体积；无效 TARGET 报错。模型内部可计分的真空区域不是自动无效区域。目标响应本轮为零也不等于目标定义非法。

### 6.3 伴随尺度与起始权重

输出伴随场是**单位人工起始源下的统计场**，不直接宣称绝对伴随重要性。保存目标响应密度的积分 Q=m 和角抽样密度 1/(4π)；绝对互易性核对时，根据实际角通量约定恢复尺度。不能只凭源频率正确就宣布响应—伴随归一化正确。

普通固定源归档源码在 `InitialBatchSource.cpp:295-298` 把实际完成 histories 写入 `p_dTotStartWgt`；变量名本身不能证明它逐历史累加了真实起始权重。F11 分别记录 N、RMC 实际分母 D 和起始权重和 W0。首版通过每个起始权重确为 1 的检查保证 N=D=W0，不对任意源权重作外推。这不是声称 RMC 的所有非单位源用法都错误，而是限制本版的归一化合同。

### 6.4 响应 RE

令 s_h,i,g 为一条完整源历史（包括所有分裂/次级后代）结束后的原始 bin score，c_i 是原计分到通量密度的转换系数。先形成

\[
r_h=\sum_{i\in I,g\in J}\frac{V_i}{V_T}c_i s_{h,i,g},
\quad S_1=\sum_{h=1}^N r_h,\quad S_2=\sum_{h=1}^N r_h^2.
\]

然后

\[
\widehat R=S_1/N,\qquad
RE_R=\sqrt{\frac{NS_2/S_1^2-1}{N-1}},\quad S_1>0,N>1.
\]

插入位置是 `SumUpTally` 中 mesh `SumTallyBin()` 清理临时 score **之前**。普通历史累计不变；新增一个目标标量统计。所有零贡献历史也属于 N，不得跳过。无需保存每条历史或全协方差矩阵。

最终各 bin 的均值可用于复核 R，但不能用各 bin 的 RE 单独相加/平方合成 RE_R，因为缺少跨 bin/群的共同历史相关性。数值舍入导致的微小负方差按预先固定容差处理，不能普遍取绝对值掩盖错误。

源码依据：`CalcFixedSource.cpp:167-203`；`SumUpTally.cpp:130-132`；`TallyData.cpp:43-51,83-99`。

## 7. Field 数值与体积归一化

### 7.1 保留物理定义，修正“直接复制 Ave”的过度结论

F10 的外部 `value[i,g]` 仍定义为源归一化、体积平均、群积分标量通量。几何为 cm 时，单位记为每单位起始源权重的 cm⁻²，不是原始计数，也不是每 MeV 的微分谱。

但旧合同“Normalize=1，因此 Ave 可原样当通量密度”的一般化需要修订。归档代码中 uniform `CalcMeshTrck` 直接返回长度，heter 路径可按 `p_bUseVol` 除体积；tally 又直接乘权重累加。E4 的内存—文本一致性只证明两种出口一致，不独立证明物理单位正确。

### 7.2 本版转换原则

Field 导出和目标 history score 使用同一份转换系数：

\[
\text{value}_{i,g}=c_i\operatorname{Ave}_{i,g},\qquad
RE_{i,g}^{\rm field}=RE_{i,g}^{\rm RMC}.
\]

对当前源码的静态推导：

| 当前路径（首版要求 Normalize=1） | 原 score 度量 | 预期 c_i |
|---|---|---|
| uniform Cartesian TL | 加权轨迹长度 | 1/V_i |
| heter Cartesian TL | 已除网格体积的加权轨迹长度 | 1 |

这是**需动态确认的候选转换表**，不是已经完成验证的生产事实。写文件时不就地修改 RMC 原始 Ave、Sum1、Sum2；不把补偿公式散落在 source、response 和 writer 三处。

优先做最小验收：同一物理几何、同样源与统计设置，用两种网格表达相同非单位体积 bins；核对 raw 值、转换值和独立轨迹长度/体积预期。仅比较两个归一化输出相等仍不够，需有可独立核算的物理参考。未通过的路径不得输出冒充 cm⁻² 的 Field，也不得用于 TARGET 响应。

本阶段不直接改普通 scorer 或更新 reference 来“通过”测试。若确认需要修复通用计分，应另立修复任务，并同步移除相应 adapter 补偿，避免重复除体积。

### 7.3 状态

- value>0 且 value、RE 有限，RE≥0：`VALID=1`。这不保证统计精度高。
- value=0 且 RE=0：`ZERO_SCORE=0`。不意味着真实通量或不确定度为零。
- 负值、NaN/Inf、负 RE、缺数据等：报错，不交给重构模块猜测。

重构后的场不复制原 MC RE。外部原始 Field 必须只读保存。

## 8. Batch 的确切边界

层级保持为：

```text
正式迭代 k
  → 一次 Adjoint 或 Forward 计算
    → RMC 内部源分配 batch
      → 一条 source history
        → 该 history 的全部后代
```

现有 batch 用于 source 分配、进度、结束等；固定源均值/RE 的独立记分单位仍是 source history。StatisticsTester 的诊断分组不是额外输运批次。对于首版串行固定 N、无停止时间/接续等设置，通常一次 run 可以在一个原生 batch 内完成。

因此首版不增加 `ADJOINT_BATCH`、`FORWARD_BATCH`，不从 `n_batches_train` 直接搬一套统计到 RMC。外部每次收到本次完成后的 Field+RE。

论文/早期原型中的逐 batch 场及 Welford 跨迭代池是后续扩展，不能将其与当前 RMC 原生 batch 混为一谈。当前选择不做历史累计，不表示永久删除该研究能力。

## 9. 输入卡

以下是本设计的语义草案，尚不是当前 RMC 已支持的语法。实际 parser 按 RMC 原风格实现，必须保证字符串路径大小写不被关键字大写处理改变。

```text
MLVR
ITERATION = 3
BOOTSTRAP_NPS = 20000
ADJOINT_NPS = 100000
FORWARD_NPS = 100000
TARGET MESH = 1 REGION = 18 20 1 1 1 1 GROUPS = 25 30
SEED = 12345
COMMAND = "/absolute/path/mlvr_worker"
WORKDIR = "./mlvr_run"
```

上例 REGION 为一基闭区间 `(xlo,xhi,ylo,yhi,zlo,zhi)`；GROUPS=25 30 为从低到高物理群的闭区间，不是 RMC 内部反向群号，也不是 MeV。解析后打印实际选定 bins、V_T、群编号及完整物理能量范围。多范围用并集并去重，具体分隔语法按既有 parser 风格定稿。

`TARGET MESH` 引用唯一 Field mesh tally ID，而不是 `OMeshInfo` 的另一种 mesh ID。导出的是整张 Field，不是只导出 TARGET 子区域。

### 9.1 与原有输入的关系

| 原有输入 | 本版处理 |
|---|---|
| 几何、材料、MGACE | 原样复用；F11 只接受规定范围 |
| `EXTERNALSOURCE` | 真实正向源唯一来源；不是由 FIXEDSOURCE 定义空间源分布 |
| `FIXEDSOURCE` | 保留固定源物理/合法 RNG type/stride 选项 |
| 显式 `PARTICLE POPULATION` | MLVR 开启时拒绝重复定义；由三种 MLVR NPS 管理 |
| 显式 `RNG SEED` | MLVR 开启时拒绝重复定义；MLVR SEED 为根种子 |
| 显式 `ADJOINT` 卡 | 与 MLVR 冲突；方向和伴随能量配置由完整流程管理 |
| `TALLY` | 复用选定 Cartesian Type=1、Energy=-1、Normalize=1 的完整 Field 定义 |
| `WWP:N` | 复用，保持整个流程不变 |
| 静态 `WWMESH`、cell WW、MCNP WW、WWG 等 | 首版拒绝与 MLVR 动态 WW 混用 |

NPS 满足现有代码的粒子数限制，当前拟定检查为整数且 >100，K≥1。读完所有 block 后统一检查，不依赖卡片出现顺序；在原 CheckFixedSource 需要总粒子数之前，把初始 N 解析为 N_B。

不启用时间停止、二进制接续、Python 源回调、自发裂变源、复杂统计/微扰可选组合等未经本版验证的副作用路径。普通 RMC 非 MLVR 模式不受这些新增限制。

首版保留原输入和 include 文件、解析后的配置与来源，不承诺当前格式化输入输出功能已能重建完整固定源+外源+MLVR 输入；需要使用该功能时另行补齐验证，不静默生成不完整的“可复跑”文件。

### 10.1 field.h5

逻辑与文件数据集都采用二维 `[Nspace,G]`；底层 C++ 使用一维 vector 不等于要求对外一维文件。

```text
/schema_version
/field/value                float64 [Nspace,G]
/field/re                   float64 [Nspace,G]
/field/status               uint8   [Nspace,G]
```

- `run_id, field_id, field_role, stage, target_id, source_id, applied_ww_id`；
- 正式 iteration，Bootstrap 没有正式 iteration；HDF5 可用 `has_iteration=false` 表示，不伪造正式第0轮；
- `requested_histories, completed_histories, normalization_denominator, starting_weight_sum, normalization_kind`；
- 网格/能群身份、单位、群积分说明、volume_conversion/scorer 路径；
- RMC revision/build、seed/type/stride/offset；伴随 source 的 Q、角抽样约定及来源。

`run_ordinal` 可从0开始用于顺序和随机数计划，但与正式 iteration 是不同概念。

## 11. 外部程序、文件和失败处理

每次流程：

```text
写 field.h5.tmp → flush并关闭 → 同目录改名field.h5
→ 启动外部可执行文件 → 等待退出
→ 核对成功退出
→ 读取外部已关闭并提交的ww.h5
→ 全部校验 → 下一次MC准备
```

固定命令参数建议 `--input <absolute field.h5> --output <absolute ww.h5>`；期望生成哪种 WW 写在 `/request` 中并回传身份。COMMAND 是可执行文件绝对路径；Python 环境、脚本和其他算法参数由一个可执行启动脚本封装。采用 Linux 的 `fork/execv/waitpid` 或等价可检查机制，不使用拼接的 `/bin/sh -c`。处理 EINTR、信号退出与错误码，保存 stdout/stderr。

WORKDIR 相对路径按输入文件所在目录解析。为整次运行创建独占目录，拒绝覆盖已有非空目录。父进程不在每轮反复 chdir；仅设置子进程工作目录。挂起命令首版允许用户终止整个任务，不暗含自动恢复；若以后增加 timeout，也只能明确失败，不自动换模型或用旧 WW。

所有逐次 field/ww/摘要文件使用局部句柄。原 RMC 进程级 Output、Total timer 和日志生命周期保留一次，不为每半轮调用整个 OutputEnding。旧 HDF5 Result/MeshTally 输出不被悄悄改造成新 schema。

记录状态可简单分为准备、输运、统计结束、外部处理中、WW已验证、失败、全部完成；无需开发通用工作流框架。失败必须保留所在阶段和诊断，且不能把整个 iteration 标成成功。

## 12. FOM 与最终物理结果

### 12.1 本版统一的时间口径

本版采用 Task 15 的“单次 MC 运行成本”口径：

\[
T_{MC,k}=T_{prepare,k}+T_{transport,k}+T_{finalize,k},\qquad
FOM_k=1/(RE_{R,k}^2T_{MC,k}).
\]

包括每次运行的清理/源与角色准备/WW三界安装、实际输运和统计结束；不包括一次性模型读入、Field文件写出、外部算法、WW文件读入。各阶段时间分别保存，实际输运时间单独可见。

这是最终合并设计的明确选择，不能将它标成“纯输运时间”，也不能与旧 `Time in Fixed Source Calculation` 的 FOM 不加说明地比较。旧普通路径计时不改；新 MLVR 指标写出 `timing_scope=prepare+transport+finalize`。若研究需要只比较采样效率，使用另外保存的 T_transport 明确另算，禁止同名指标混用。

全局 Total 保留为整次运行时间；每次 MC 使用独立区间/差分计时。当前 Timer 的 reset 没有清 recordTime，正式重复运行不能只调用它就假定全部状态归零。

R>0、0<RE_R<∞、T_MC>0 时才形成有效 FOM。R=0 为零得分；RE_R=0 不自动产生无穷大排名。缺失/无效 FOM 保存原因，不用 epsilon 伪造。

### 12.2 不把框架输出当成成品计算

F11 v1 运行固定 K，保存全部 Forward 的 R/RE/FOM、全部 Field 和全部 WW。不把最后一张 WW 自动命名为最佳，不做 best-anchor 反馈和自动生产计算。

后续最优候选选择可根据这些独立存档进行，但统计涨落下的最大训练 FOM 不是“已证明真实最优”。最终科学响应应来自另行固定 WW、独立随机数统计的成品 Forward run；它不是本版 2K+1 次开发闭环的一部分。保存训练场不等于允许无条件合并多个自适应 iteration 的统计误差。

| 1：抽出固定源核心 | 保留普通包装入口，抽init/execute/finalize | 普通固定源、现有伴随和native WW代表回归；抽取影响的旧粒子/编译分支运行相应既有回归，不以编译成功代替数值回归；同种子物理结果一致；只一份history loop |
| 2：正式重复运行 | owner级reset，F→F、F→A→F、A→A | 每次独立进程对照；计数/分母/源/角色/缓存/统计/WW一致；登记不增长；无初始化重读 |
| 3：输入、TARGET和响应 | MLVR解析；普通源表示构造伴随源；history级目标统计 | 非等体积目标、多群、概率/空间/方向/起始权重；目标R和RE独立核算；归一化互易/解析验证 |
| 4：Field与WW文件 | 专用schema、完整边界、数值转换、导入三界 | 用3×2×2等不对称小网格和逐群不同值检查所有轴；错误维度/群/身份/非有限值拒绝；真实查窗命中更新值 |
| 5：外部调用 | 实际启动、等待、日志与失败处理 | stub返回已知WW；非零退出、信号、缺文件、旧文件、半写文件、带空格路径；失败后没有下一条MC history |
| 6：闭环与归档 | Bootstrap、K=1、K=3，所有记录 | 3/7次MC与3/7次外部调用；最后WW_A2/WW_A4保存未使用；每次对照fresh；FOM复算；资源无持续增长 |

新增响应、Field和WW接口的数值检查必须包括零得分、首末能群和不同空间轴；仅2×1×1测试不足以排除y/z展平错误，这是文件接口的针对性验证而非无限模型矩阵。

**裂变开放条件**：使用具有非零裂变产生项且固定源响应有限的多群模型，验证 F→A→F→A 的伴随散射/裂变数组、后代库、统计和 fresh 对照；通过后再移除对应范围限制。不因 H2O E2 通过自动开放，不为通过而改变裂变物理。

测试中的新/旧普通程序对照，与新程序内部F11/独立单次对照是两个层次，均需保留。不能只比较两条都使用同一个错误转换的新路径。
