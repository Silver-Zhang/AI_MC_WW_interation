## 1. 目标与范围

独立判断源物理 MeV 是否误作为内部群号初始化速度，是否越界、是否影响首次飞行，以及碰撞后和后代是否正确更新。本次只验证、归档，不实施修复或 Stage 3。

**物理解释**：内部群号必须先映射到真实 MGACE 群中心才能计算群速度。群号本身不带 MeV 单位。正确群号和空间轨迹并不足以证明速度、累计时间或内存访问正确。独立参考由数据库中心及相对论公式计算，速度相对容差预先固定为 1e-12。

## 4. 结论与边界

**CONFIRMED / P1 / E3；未修复。**

| 已确认问题 | 关键数值 / 意义 |
|---|---|
| 源初始化把物理能量当内部群号 | 合法 E<0.5 MeV 导致 k=30、size=30，F/A均复现堆越界 |
| 合法索引也会选错群速度 | E=0.6615 MeV：实际54.6310903661、正确11.2436646336 cm/shake |
| 首次飞行时间错误 | 同一首段：实际0.0138567200019、正确0.0673274903934 shake；热群本次运行初速0，时间变为inf |
| 后代出栈反向混用坐标 | native WW 内部群14被当14 MeV；实际51.1828591292、正确8.76144641452 cm/shake |

**结果解释**：源群号在后续转换正确，不能补救已经发生的越界和错误初速。碰撞后速度恢复正确，也不能回溯修正累计时间。source 与 bank 两个入口均需按各自能量表示处理，不能仅在 Stage 3 新源层绕过问题。

**边界**：普通 standard MGACE neutron Forward/Adjoint 共享缺陷，非 F11 专有。没有证据据此宣布已有稳态通量、反应率或正向—伴随响应错误。时间分箱/速度估计器的输出偏差、裂变后代、CE、photon/coupled、MPI/OMP、AIS/Python 等未动态覆盖；sanitizer仅插桩三个相关生产单元，不代表全程序安全审查。

**历史边界**：F02 未覆盖源初速/首次时间/内存安全；F03 阅读过相关采样链，但漏查速度函数表示合同，原动态群号与稳态响应检查不能观察该问题。不自动否定此前全部 F02/F03 有界验收。

**下一步建议**：在 Stage 3 生产实施前，另行授权 RMC 通用修复，处理 `SampleParticle()` 的 MG 速度初始化及 `SampleFromParticleBank/PopParticleOutofStack` 的速度恢复；补低中高群 F/A、首次时间、ASan、bank 后代及代表性历史回归。未获得生产修改授权，不开始修复。
