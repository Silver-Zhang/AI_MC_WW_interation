# 5. 找出“昂贵且理论上可复用”的初始化

逐项调查：

## Geometry

- geometry 在哪里建立？
- 是否在 fixed-source run 过程中改变？
- 能否一次初始化，多次 transport 复用？

## Material / nuclear data

重点：

- XSDIR / ACE / MGACE 在哪里读取？
- cross section 数据保存在哪里？
- 生命周期多长？
- Forward / Adjoint 是否共享同一数据？
- 切换 adjoint mode 是否需要重新读取 nuclear data？

## Mesh / tally

- mesh 何时创建？
- tally storage 何时 allocate？
- 每次 run 后如何 clear？
- 是否已有 reset/clear 操作？
- 能否保留 mesh definition，只清 statistical accumulation？

## Weight Window

- input parsing
- runtime object
- lower bounds storage
- energy mapping
- lookup

分别在哪里？

重点回答：

> 如果外部已经计算出一张新的 WW，
> 当前代码是否可能只替换 WW 数值，而不重新读取完整 RMC input？

指出具体数据结构和依赖。
