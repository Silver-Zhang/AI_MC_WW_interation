# 2. Frozen F11 v1 functional requirements

以下是物理/功能需求，不是代码架构答案。

F11 v1：

- standard MGACE
- neutron fixed-source
- serial first
- Cartesian mesh field
- native track-mesh WW
- fixed iteration count K
- Bootstrap 不计入 K
- 一个 formal iteration = Adjoint + Forward

运行流程：

Bootstrap Forward
→ field + RE
→ external reconstruction / WW mapping
→ WW_A(1)

for k = 1...K:

    Adjoint
    using WW_A(k)
    → adjoint field + RE
    → external reconstruction / WW mapping
    → WW_F(k)

    Forward
    using WW_F(k)
    → forward field + RE
    → response / response RE / FOM
    → external reconstruction / WW mapping
    → WW_A(k+1)

第一版简单 TARGET：

- existing Cartesian tally mesh 中的一个或多个 spatial bins
- 一个或多个 physical MG groups
- nonnegative scalar flux response

RMC 内部负责：

- K
- Bootstrap / Adjoint / Forward 顺序
- Forward physical source
- TARGET definition
- simple TARGET → adjoint source
- per-run population
- existing fixed-source batch mechanics
- Forward / Adjoint state switching
- run reset / preparation
- tally
- response / RE / FOM
- WW loading and application
- per-iteration output
- calling external reconstruction executable

外部程序负责：

Field + RE
→ field reconstruction
→ WW mapping
→ output next WW lower-bound field

第一版文件交换：

RMC → `field.h5`
external → `ww.h5`

外部只返回 WW lower bounds；
RMC 自己生成 survival / upper。

现有 source / tally / WWP 定义尽量复用。
