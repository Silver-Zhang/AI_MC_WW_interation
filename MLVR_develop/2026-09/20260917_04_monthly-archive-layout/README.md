**验收标准**：
1. 任务目录均位于 `YYYY-MM/<YYYYMMDD_NN_名称>/`；

3. INDEX 链接零断链；
4. 建档、清理、归档检查脚本在新结构下可用；
5. `bash tools/check-archives.sh` 无“需处理”项。

**原始材料**：无外部报错；依据为用户 2026-09-17 的整理要求与本轮盘点输出。
