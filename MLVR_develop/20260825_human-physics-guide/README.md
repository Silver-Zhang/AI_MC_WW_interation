## 1. 任务定义（① 立项 · Agent 填）

**目标**：建立一个独立、长期维护、面向“懂输运物理但不要求懂代码”的人类可读文档区；将 F02 当前能力结论及 W5/W6/W7 的物理含义、结果风险、证据边界和修复顺序整理为可直接阅读的文档。

**范围**：仅修改本工作区文档和维护约定；不修改 `RMC/`、`AIMC_WWiteration/`、reference、benchmark 或物理结果。

**验收标准**：

1. 新目录有清晰入口、读者定位、状态词和维护原则。
2. 用物理语言解释 W5/W6/W7，明确区分代码错误、物理模型选择、核数据和未验证内容。
3. 单独总结当前能力边界、已有正证据、对 ML-VR/WW 的影响和下一步顺序。
4. 根导航、知识库、快速上下文及 Agent 规则均登记该目录，保证后续结论变化时同步维护。
5. 文档链接和编辑器诊断检查无误；RMC 工作树保持不变。

**原始材料**：用户明确提出“工作流文档不便于人类查看，希望单独建立面向懂物理、不懂代码开发和软件工程读者的内容目录”。本任务不保存原始聊天转储；物理事实引用既有 F02 静态审查、数值验证和 Claude 独立复审。
