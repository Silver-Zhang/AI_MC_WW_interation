# 流程图与时序图

本页的图只描述当前 standard ACE、`ais=OFF`、MGACE fixed-source neutron adjoint 的实际组织方式。图中的“伴随源”是 RMC 接收的外源并标记为伴随历史；它不表示 F03 的响应驱动伴随源语义已经验证。

## 1. 功能总流程

```mermaid
flowchart TD
    A[输入卡] --> B[多群核数据]
    A --> C[材料与局部密度]
    B --> D[初始化伴随群产生核]
    C --> D
    A --> E[给定外源]
    D --> F[标记伴随中子历史]
    E --> F
    F --> G[抽样飞行距离]
    G --> GA[按实际飞行段累积径迹长度 tally]
    GA --> H{先到几何边界?}
    H -->|是| I[更新区域材料与密度]
    I --> G
    H -->|否| J[到达碰撞点]
    J --> JA[累积启用的碰撞 tally]
    JA --> K[按伴随产生量选择核素和反应]
    K --> L{散射还是裂变?}
    L -->|散射| M[反向群对抽样与方向更新]
    M --> N[更新伴随权重]
    L -->|裂变| O[选择前驱群并产生一个后继]
    O --> P[后继放入粒子银行]
    P --> Q[母粒子终止]
    N --> R{满足终止条件?}
    R -->|否| G
    R -->|是| S[结束当前粒子历史]
    Q --> S
    S --> T{银行仍有历史?}
    T -->|是| U[取出下一条后继历史]
    U --> G
    T -->|否| V[汇总当前外源及全部后继的统计量]
    V --> W[批次与最终输出]
```

**物理解读。** 核数据、材料组成和局部密度共同决定飞行与碰撞。初始化把正向群间产生关系整理为伴随抽样所需的量；运行时则反复执行飞行、逐段 tally、边界、碰撞和权重更新。裂变后继不会立刻与母粒子混在同一历史中，而是进入等待追踪的粒子银行。初始外源及其全部银行后继构成一个源历史簇；处理完整个历史簇后才进行历史级汇总，最终形成指定 tally 定义下的批次结果。

**边界。** 图只说明组织顺序，不代表每个环节都已通过物理验证；W5、W6、W7 的位置见第 4 图。

## 2. 单粒子历史

```mermaid
flowchart TD
    A[从外源或银行取一条伴随历史] --> B[计算当前群总截面]
    B --> C[抽样碰撞距离]
    C --> CA[沿本段实际飞行距离累积径迹长度 tally]
    CA --> D{边界先到?}
    D -->|是| E{泄漏或终止?}
    E -->|是| Z[结束此历史并记账]
    E -->|否| F[穿越边界 更新材料和局部密度]
    F --> B
    D -->|否| G[到达碰撞点]
    G --> GA[累积启用的碰撞 tally]
    GA --> H[按伴随产生量选择核素]
    H --> I[选择伴随散射或伴随裂变]
    I --> J{散射?}
    J -->|是| K[抽样正向前驱群和散射方向]
    K --> L[更新群 方向 权重]
    L --> M{能量或追踪条件终止?}
    M -->|否| B
    M -->|是| Z
    J -->|否| N[抽样裂变前驱群]
    N --> O[将一个加权后继加入银行]
    O --> Z
```

**物理解读。** 一条历史不是只在碰撞时发生变化：每段实际飞行都会产生径迹长度贡献，边界可先于碰撞并使局部材料与密度改变；真正到达碰撞点后还可产生碰撞估计量。散射把当前伴随群映射到正向会产生该群的前驱群；裂变则终止母历史，同时留下可继续追踪的后继。吸收不产生伴随后继，而是通过总截面损失项和权重比进入计算。泄漏、能量上限和裂变母粒子终止都会结束当前粒子历史。

## 3. 初始化与运行时序

```mermaid
sequenceDiagram
    participant I as 输入与运行控制
    participant M as 多群核数据与材料
    participant S as 伴随源
    participant P as 粒子历史
    participant G as 几何追踪
    participant C as 碰撞与裂变抽样
    participant B as 粒子银行
    participant T as Tally与输出

    I->>M: 读取MGACE 群结构 材料和密度
    I->>M: 启用固定源伴随模式
    M->>M: 初始化伴随散射与裂变产生分布
    I->>S: 读取给定外源和伴随上限
    S->>P: 生成并标记初始伴随中子
    loop 直到初始外源及银行后继全部处理完
        loop 当前粒子存活
            P->>G: 按正向总截面推进一个实际飞行段
            G->>T: 累积该飞行段的径迹长度贡献
            alt 边界先到
                G->>P: 更新区域和局部密度
            else 到达碰撞
                G->>T: 累积启用的碰撞估计量
                G->>C: 提交当前群与核素候选
                C->>C: 按伴随产生核选择反应
                alt 散射
                    C->>P: 反向群对 方向 权重更新
                else 裂变
                    C->>B: 加入一个加权后继
                    C->>P: 终止母粒子
                end
            end
        end
        alt 银行仍有后继
            B->>P: 取出下一条后继历史
        else 银行为空
            T->>I: 汇总当前源历史簇
        end
    end
    T->>I: 写出批次与最终能群统计结果
```

**物理解读。** 最关键的分界是初始化与运行时：初始化预先建立群产生分布；运行时实际用这些分布选择反应、群和权重。W6 正是在这两阶段采用的裂变核之间出现不一致。tally 在飞行段和碰撞点即时计分，银行后继则在当前粒子终止后由外层调度继续追踪；粒子银行是裂变后继的延迟追踪机制，而不是额外的物理反应。

## 4. 缺陷定位与传播

```mermaid
flowchart LR
    A[材料基准密度与局部比例 r] --> B[正向宏观总截面]
    A --> C[伴随产生量与权重归一化]
    B --> D[飞行与碰撞权重]
    C --> D
    E[双 nubar 核数据] --> F[初始化裂变产生核]
    E --> G[运行时裂变群抽样核]
    F --> H[裂变概率与权重]
    G --> H
    I[伴随初始化] --> J[中子群上限定位]
    I --> K[photon 群上限定位]
    D --> L[伴随重要性 tally]
    H --> L
    J --> L
    K --> X[W7 修复前 告警或崩溃]
    D -. W5 .-> Y[额外 1/r 权重因子]
    H -. W6 .-> Z[裂变核混用且无补偿]
    L --> W[未来权重窗或重要性使用]
```

**物理解读。**

- **W5** 位于局部密度进入飞行和权重比的连接处。共同密度因子本应在产生量/总截面比中抵消；额外 $1/r$ 会直接污染碰撞后的重要性权重，并可传递到空间—能群重要性分布。
- **W6** 位于“初始化建立的裂变核”与“运行时实际抽样的裂变核”之间。若这两套核不同却没有补偿，裂变前驱群的概率和携带权重不再对应同一物理算子，可能扭曲可裂变区域的能群重要性关系。
- **W7** 位于伴随初始化、粒子类型与能群访问阶段。纯中子数据不应要求 photon 群；修复前的错误访问在数据碰巧带 photon 群时表现为无关告警，在没有 photon 群时可在输运开始前崩溃。当前工作树已改为按粒子模式分别定位 neutron/photon 上限，纯中子路径不再进入图中的错误分支。

这些缺陷并不自动给出某个未运行 MLVR 算例的数值误差，但足以阻止把当前完整伴随能力作为可靠权重窗基础放行。

## 5. W7 修复后的初始化门控

```mermaid
flowchart TD
    A[进入 fixed-source 初始化] --> B{启用伴随计算?}
    B -->|否| Z[继续普通初始化]
    B -->|是| C{运行模式包含 neutron?}
    C -->|是| D[用 neutron 群边界定位 neutron 上限]
    C -->|否| E{运行模式包含 photon?}
    D --> E
    E -->|是| F[用 photon 群边界定位 photon 上限]
    E -->|否| G[跳过 photon 群访问]
    F --> H[继续后续初始化与输运]
    G --> H
```

**物理解读。** 两个粒子判断彼此独立：是否需要 neutron 群，只由本次模式是否包含 neutron 决定；是否需要 photon 群，也只由模式是否包含 photon 决定。纯中子路径经过 neutron 上限定位后，会明确走“跳过 photon 群访问”的分支，因此 photon 群不存在不再构成异常。耦合模式仍会依次定位两类上限，没有删去其原有初始化。

修复只改变能群结构的访问条件，不改变最大能量到群号的映射方法，也不改变截面、散射、裂变或权重公式。完整的判断表、修复边界和验证结果见[缺陷解读](04_三个已确认缺陷的物理解读.md#w7纯中子初始化却访问-photon-群)。
