# 当前能力与验证结论

## 结论

RMC 当前 **standard MGACE fixed-source neutron adjoint** 完整能力为：

> **A — Ready（有界）：MPI-off serial build 的逐运行 formal、严格统计门槛与 source—binary provenance 均已闭合。**

历史 C 仅指先前证据尚未闭合时的 Linux serial、`ais=OFF`、standard ASCII MGACE fixed-source neutron adjoint 声明工作树快照；不等同于发现新的 RMC 物理 defect，也不等同于 RMC 所有伴随模式或所有平台 Ready。

## 先区分五类事实

| 类别 | 当前事实 |
|---|---|
| 物理模型选择 | 伴随裂变究竟采用 prompt-only 还是 total 核，需要物理模型明确；两者不能无补偿混用。 |
| 核数据事实 | `c5g7td` 有两组不同 nubar 数据；H/O 回归数据带 photon 群。 |
| 数值抽样方法 | 当前路径按正向总截面飞行，按伴随产生量选择核素/反应，并用权重修正。 |
| 已确认实现错误 | W5/W6/W7/W9 均已修复并通过各自针对性验证。 |
| 已闭合扩展门槛 | 其余四类条件角表示、真实 HDF5 density mesh、NNUBAR=1 与双裂变核混合材料均完成预冻结 formal。 |
| 未验证范围 | photon/耦合粒子、CE、AIS/HDF5 核数据、delayed、反射边界、MPI/OpenMP、Windows 和任意机制组合。 |

## 已确认缺陷及修复

- **W5（已修复）：** 修复前在局部密度比例 $r\ne1$ 时，伴随碰撞权重多出 $1/r$。当前工作树让散射和裂变权重都用局部总原子密度 $N_0r$ 归一化宏观总截面；同一 V2 输入的首碰撞后权重由约 $2:1:0.5$ 变为严格 $1:1:1$，$r=1$ 原生轨迹逐字节不变。
- **W6（已修复）：** 修复前双 nubar 数据下初始化与运行时使用不同核。当前运行时改用 total nubar getter；部署数据的逐群核与归一化概率差均为 0，10,000 历史重放产生 2,487 条 bank 后继并退出 0。
- **W7（已修复）：** 修复前伴随初始化无条件定位 photon 群；H/O 数据只出现无关 warning，纯中子 `c5g7td` 输入则在第一条 source state 前 SIGSEGV。当前工作树按粒子模式分别定位上限后，同一输入退出 0，完成 10,000 个源历史并记录 12,487 条初始/后继粒子状态。

四项已知缺陷均已闭合；随后原 C 门槛的 formal 汇总已完成。Claude 独立审核指出 angular/density formal 缺少逐运行 raw transport 输出且 angular checker 未强制逐 seed 门槛；任务 04 在同一冻结快照重跑 50 条 formal，保留每条原始输出，并以 strict checker 和 checksum manifest 独立闭合该缺口。

### W9：负单变量伴随角核支持域越界（已修复）

`NLEG=1` 的单个表值 $x$ 表示目标均值。对 $x<0$，前向采样

$$\mu=-1+2\xi(1+x)$$

给出支持域 $[-1,1+2x]$ 和均值 $x$。修复前伴随分支却实现为 $-1+2\xi(1-x)$；当 $x=-0.5$ 时，其原始范围扩展到 `[-1,2]`，随后方向归一化会隐藏部分非法幅值，但不会恢复正确角分布。当前已将该分支修正为 $1+x$。

任务 11 用五类私有一群 MGACE 完成 NXS/JXS/XSS、locator、截面、支持域、矩和 SHA256 的独立 readback。正式低光学厚度对照采用 5 cm 球、原子密度 `0.001×10^24 cm^-3`、每模式 100000 histories、seed 17。前向真实 collision PTRAC 校准显示重建器假阳性 0、漏检 1；最终前向 `0/509` 越界，伴随 `161/330` 越界，伴随最大余弦约 `0.994`。可混入的多碰撞历史期望上界约 4.963，观察至少 161 条的 Chernoff 上界小于 $10^{-175.52}$，不能解释该差异。

修复后以 seeds 17/23/41、每 seed 每模式 100000 histories 重跑同一低光学厚度 neutron 路径。三组分别重建 509、462、467 对样本；前/伴随逐项完全一致，合计 1438 对均为零越界。三组均值 $z=0.830,-0.062,-0.160$，合并均值 `-0.497205`、$z=0.367$；五类 MGACE oracle、既有 CTest 与 reference 完整性均通过。

随后对普通伴随 photon 与 photon→neutron 次级的两个同形负分支分别建立私有表并独立读回。修复前一群资产上的 200 个生产函数返回值分别有 130 和 144 个超出 `[-1,0]`，最大值达到 `1.9694` 与 `1.9967`；逐路径确认后，两处公式也改为 $1+x$。旧一群整程虽完成，但每个 400-history 运行有 401/402 条能群下界 warning，不能称为干净成功；这来自单群能量定位恒返回索引 0。为分离验证构造告警，另建中心 `[3,1]` MeV、宽度 `[2,2]` MeV 的两群资格资产，3 MeV 源合法落在上群。两路径三 seed 的 6/6 整程和 9/9 生产采样日志均零 Warning/零 Error；普通 photon 合并均值 `-0.500278`、$z=-0.289$，次级合并均值 `-0.482753`、$z=1.792$，两者均零越界，普通 photon 的 900 个正向/伴随样本逐项一致。该结果只闭合两个条件角分支，不证明完整 photon 或耦合粒子伴随能力。

## 已有正证据：从局部机制到冻结扩展矩阵

### V0：既有回归

当前 SHA 的旧 H/O 回归 1/1 passed，重建结果与 reference 字节一致。它证明该历史用例没有相对 reference 回归，并不证明一般伴随物理正确；日志仍出现 photon 上限 warning。

### V4：两个群对的标量互易性检查

在 $r=1$、`NNUBAR=0`、30 群 H/O 均匀球、各向同性体源、同一区域标量 track-length flux 响应下，前向/伴随交换能群后测试了两个强非对称群对：14→15 与 20→22。每对五个种子、共 20 个运行；合并统计量为

$$z=-0.2587,\qquad z=0.0829.$$

在预设 $|z|\le3$ 标准和当前样本量下，**未检测到显著差异**。

这不能写成严格互易性证明：它不覆盖更多群对、混合材料、非均匀密度、裂变、各向异性、一般边界/几何或不同源—响应。前/伴随使用相同 seed，统计误差合并采用独立估计假设；这也是解释结果时必须保留的边界。

### W5 双区域：跨密度界面的响应级互易性

修复后的代表性验证把同组成 H/O 分成等体积内球和外壳，分别采用 $(r_{inner},r_{outer})=(0.5,2.0)$ 与 $(2.0,0.5)$。正向计算从一个区域均匀发射并在另一区域统计积分径迹响应；伴随计算交换空间区域和能群。两区域等体积，因此源归一化与响应积分的体积因子相同，可直接比较原始响应。

200k/运行的第一批 40 个算例中，四个五种子合并量和总体都满足 $|z|\le3$，但一个单种子为 $z=-4.007$，所以预设的“所有单种子也通过”总判据失败。保留全部原数据后，对同一 40 个组合统一提升到 1M/运行；原离群回归到 $z=-0.986$，20/20 单种子均通过，四组合并为

$$z=1.106,\quad -0.824,\quad 0.400,\quad -0.367,$$

总体逆方差合并为 $z=0.116$。这支持 W5 修复在所测跨界面完整历史中保持响应互易性；精度升级是在观察离群后进行，且前/伴随共用 seed 标签、协方差未单独估计，因此不能冒充事前独立的普遍证明。

### V3/W6：双 nubar 的功效边界与确定性修复验证

修复前实际数据上的群概率差很小，使用正态近似得到约 $7.33\times10^7$ 个已观测伴随裂变子代的 80% 功效量级。它是规划尺度，**不是精确 multinomial 样本量保证**。本次没有用低功效动态频数冒充证明，而是检查生产 locator 并解析同一部署核表：运行时与初始化的 total $\nu\Sigma_f$ 核逐群相等，最大归一化概率差为 0。动态重放证明真实分支和 bank 可达、无崩溃；下一节另以最终响应检验整条路径。

### W6 可裂变最终响应：单一裂变主导群对

在均匀 2 cm 球和部署 `10001.01m` 双 nubar 数据中，选择 ACE `g6→g1`：裂变算子强度为 `0.100120227799`，双向直接 P0 散射均为 0，因此跨群信号由裂变耦合主导。前向从 g6 发射并测 g1，伴随交换源/响应群；五组前向和伴随采用互不重叠的随机流，每个运行 1M histories。

正式 10/10 运行正常结束且无异常。五组统计量均满足 $|z|\le3$，最大 $|z|=2.033$；逆方差合并为

$$R_F=0.2419981,\qquad R_A=0.2425594,\qquad z=-0.703.$$

这表明当前样本精度下未发现该裂变主导响应对的前向—伴随不一致。它补足了最终响应层证据，但不证明其他群对、材料、几何或 delayed/各向异性路径。

## 冻结扩展矩阵

在早期局部案例之后，三个独立任务关闭了原 C 门槛：

1. **条件角表示**：isotropic、正单变量、等概率 multi-bin、discrete-cosine 四类各做 forward/adjoint × 五 seeds，共 40/40 clean；40,000 个生产函数返回样本通过严格支持域、均值、bootstrap 方差或 Pearson 频数判据。旧“强 P1/P2”不是准确物理术语；这些是 MGACE 群对条件余弦表示，不是传统 Legendre P1/P2 矩。
2. **真实 density mesh**：私有 HDF5 两区域密度值由独立工具读回；位置依赖碰撞率约为每源 2.10 与 20.11，证明运行时查询生效；五组前向/伴随共 10/10 clean，合并 $z=0.0984$。
3. **NNUBAR=1 与混合裂变材料**：部署 `10005.01m` 纯材料和 `10005:10001=0.9999:0.0001` 的 NNUBAR=1 主导混合材料，各五对正式流，共 20/20 clean；合并 $z=0.9563$ 与 $0.3748$。

task 05 虽闭合 source—binary 身份，但属于 MPI-enabled one-rank execution，不能替代严格 MPI-off serial 标签。任务 01 用声明的 `6d208751... + W9 diff` 显式 `-Dmpi=OFF` 做全新 configure/build，运行 banner 为 MPI OFF、OpenMP OFF；其上重跑上述 angular 40/40 与 density 10/10，raw reports、strict reports、diff 与 binary 的 SHA256 清单均通过复验，fixed-source regression 1/1 passed，独立审计 ACCEPT。因此，对已声明的 MPI-off serial 冻结作用域，当前等级为 **A — Ready（有界）**。

几何证据已包括真空球、内球/外壳和左右双盒，覆盖泄漏、曲面/平面穿越、空间源响应交换及材料/密度界面。冻结 F02 需求没有要求无限枚举几何；反射边界等未测机制应在真实问题需要时单独审查，而不是让“更多几何”成为没有终点的门槛。

尚未覆盖且不属于该 A：完整 photon/耦合粒子、CE、AIS/HDF5 核数据、delayed、GPT、反射边界、MPI/OpenMP、Windows，以及 density mesh × 裂变 × 强角分布等任意组合。

## 对 MLVR 的含义

W9 修复消除了负单变量角核对空间—能群重要性传播的已确认偏差；其余角核、density mesh 和裂变/材料的 formal 已由可独立审计、且可归属冻结 source snapshot 的逐运行证据补齐。伴随源、场、RE 和 WW 组合仍须分别通过 F03/F06/F07/F04，不能由 F02 自动继承。
