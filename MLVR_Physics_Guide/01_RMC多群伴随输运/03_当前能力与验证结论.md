# 当前能力与验证结论

## 结论

RMC 当前 **standard MGACE fixed-source neutron adjoint** 完整能力为：

> **E — Defect：存在已确认实现错误，不能作为完整、可靠的 MLVR 伴随求解基础。**

这是完整能力分级，不等于每一个算例都会失败。当前存在 W5、W6、W7 三项已确认问题；同时也有一个严格受限的非裂变代表案例提供局部正证据。两者不矛盾。

## 先区分五类事实

| 类别 | 当前事实 |
|---|---|
| 物理模型选择 | 伴随裂变究竟采用 prompt-only 还是 total 核，需要物理模型明确；两者不能无补偿混用。 |
| 核数据事实 | `c5g7td` 有两组不同 nubar 数据；H/O 回归数据带 photon 群。 |
| 数值抽样方法 | 当前路径按正向总截面飞行，按伴随产生量选择核素/反应，并用权重修正。 |
| 已确认实现错误 | W5 的 $1/r$、W6 的双核混用、W7 的无条件 photon 群访问。 |
| 未验证风险 | 强各向异性、混合材料无偏性、裂变 bank 动态行为、一般几何等。 |

## 已确认的负面结论

- **W5：** 在局部密度比例 $r\ne1$ 时，伴随碰撞权重多出 $1/r$；源码数据流和 $r=0.5,1,2$ 原生轨迹均确认这一规律。
- **W6：** 双 nubar 数据下，初始化裂变产生核与运行时前驱群抽样核不同，且无重要性补偿；静态/核数据证据确认。动态群频数、bank 和最终响应误差幅度尚未测量。
- **W7：** 伴随初始化无条件定位 photon 群；H/O 数据只出现无关 warning，纯中子 `c5g7td` 输入则在第一条 source state 前 SIGSEGV。

任一项都阻止完整能力放行。

## 已有正证据：非常窄的代表案例

### V0：既有回归

当前 SHA 的旧 H/O 回归 1/1 passed，重建结果与 reference 字节一致。它证明该历史用例没有相对 reference 回归，并不证明一般伴随物理正确；日志仍出现 photon 上限 warning。

### V4：两个群对的标量互易性检查

在 $r=1$、`NNUBAR=0`、30 群 H/O 均匀球、各向同性体源、同一区域标量 track-length flux 响应下，前向/伴随交换能群后测试了两个强非对称群对：14→15 与 20→22。每对五个种子、共 20 个运行；合并统计量为

$$z=-0.2587,\qquad z=0.0829.$$

在预设 $|z|\le3$ 标准和当前样本量下，**未检测到显著差异**。

这不能写成严格互易性证明：它不覆盖更多群对、混合材料、非均匀密度、裂变、各向异性、一般边界/几何或不同源—响应。前/伴随使用相同 seed，统计误差合并采用独立估计假设；这也是解释结果时必须保留的边界。

### V3：双 nubar 的功效边界

实际数据上的群概率差很小，使用正态近似得到约 $7.33\times10^7$ 个已观测伴随裂变子代的 80% 功效量级。它是规划尺度，**不是精确 multinomial 样本量保证**。动态尝试在输运开始前被 W7 阻断，因此未把功效估计伪装成动态验证。

## 受限子域的等级

对于明确排除 W5/W6 条件的更窄范围——至少 $r=1$、非裂变/`NNUBAR=0`、H/O 均匀球、两个 V4 群对和当前 tally 设置——可说“存在局部正证据”，但整体仍应为 **C — Verify**，而不是 A — Ready。

尚未覆盖：混合材料碰撞估计器、其他群对、强各向异性、非对称空间源/响应、可裂变 bank/权重、delayed 路径、AIS/HDF5、continuous-energy、MPI/OpenMP、Windows。

## 对 MLVR 的含义

伴随场若用作重要性或权重窗的依据，W5 会把局部密度映射成非物理权重缩放，W6 会扭曲裂变能群的重要性关系，W7 则使部分合法问题无法产生伴随结果。局部 smoke 或 V4 的通过都不能抵消这些系统性能力缺口。
