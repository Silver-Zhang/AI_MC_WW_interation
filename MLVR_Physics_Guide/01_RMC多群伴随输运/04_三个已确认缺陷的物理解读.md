# 已确认缺陷的物理解读

W5/W6/W7/W9 都针对当前 standard ACE、`ais=OFF`、MGACE fixed-source neutron adjoint 路径。它们不是“核数据天然有问题”，而是核数据、局部密度、粒子类型或角分布进入计算时，实际实现没有保持应有物理一致性。四项均已修复并完成针对性验证。

## W5：局部密度没有在伴随权重比中抵消

### 物理对象与正确关系

同一种材料只改变局部原子密度时，散射/裂变产生量与总截面都应乘同一个局部比例 $r$。若采用产生量/总截面形式的伴随权重修正，该公共因子应抵消：

$$w'\propto\frac{r\Sigma_{prod}^\dagger}{r\Sigma_t}=\frac{\Sigma_{prod}^\dagger}{\Sigma_t}.$$

局部密度应影响平均自由程和碰撞位置，但不应额外改变同一材料、同一群、同一反应关系的碰撞权重比。

### 修复前偏差与结果影响

RMC 用含 $r$ 的局部密度形成飞行的宏观总截面，但权重分母用未缩放的材料基准总原子密度归一化。因此实际权重变成

$$w'_{code}=\frac{1}{r}w'_{expected}.$$

低密度区域的伴随权重被放大，高密度区域被压低。若这种伴随结果用于重要性或权重窗，会把物理密度变化之外的人工缩放带入空间—能群重要性分布。

### 为什么旧测试没有发现

旧回归和 V4 都固定 $r=1$，此时错误因子恰为 1。V2 只改变 cell `DENS` 为 $r=0.5,1,2$，记录首个碰撞后原生状态，观察到约 $2:1:0.5$ 的权重比例；固定 RNG 重跑哈希一致。

### 修复逻辑：分母使用当前位置的总原子密度

修复不改变宏观总截面的计算，也不从飞行过程中删除密度。它只修正从宏观总截面恢复“每原子平均总截面”时使用的密度：

| 量 | 修复前 | 修复后 |
|---|---|---|
| 飞行用宏观总截面 | $\Sigma_t^{macro}=N_0r\,\bar\sigma_t$ | 不变 |
| 权重分母 | $\Sigma_t^{macro}/N_0=r\bar\sigma_t$ | $\Sigma_t^{macro}/(N_0r)=\bar\sigma_t$ |
| 人工密度因子 | $1/r$ | 无 |

程序在散射与裂变两个伴随权重调用点，都改用现有的“材料基准原子密度乘当前位置比例”接口。于是当前 cell 或密度网格的 $r$ 同时出现在宏观总截面与归一化密度中，二者抵消：

$$
w'_{fixed}=w\frac{\bar\sigma_{prod}^\dagger}
{\Sigma_t^{macro}/(N_0r)}
=w\frac{\bar\sigma_{prod}^\dagger}{\bar\sigma_t}.
$$

### 修复没有改变什么

局部密度仍决定平均自由程、碰撞位置、泄漏概率和径迹长度 tally；修复只移除碰撞权重中重复引入的密度效应。材料组成、能群转移、散射方向、裂变核和正向输运均未改变。因此 W5 修复不能替代 W6 裂变核修复；后续双区域验证增强了代表性非均匀问题的证据，但不等于一般密度场已全面验证。

### 修复与验证状态

同一组固定 RNG、128 粒子的 V2 输入在修复前得到约 $2:1:0.5$；修复后 $r=0.5,1,2$ 三组的首碰撞后平均、最小和最大权重均为 `0.66903`，相对比严格为 $1:1:1$。$r=1$ 的原生 `.source` SHA256 修复前后相同，既有伴随回归 1/1 通过且 reference 哈希不变。

这确认 W5 的确定性 $1/r$ 因子已消除。进一步的响应级验证使用等体积内球/外壳、两种相反局部密度排列，交换空间源/响应与群 14↔15、20↔22。200k 批次因一个单种子 $z=-4.007$ 未通过严格总门槛；保留原数据后统一增至 1M/运行，40/40 正常退出，20/20 单种子、四组合并和总体 $z=0.116$ 均通过。此后真实 HDF5 两区域 density mesh 又完成 10/10 clean formal，合并 $z=0.0984$；这些结果覆盖代表性的 cell/mesh 非均匀密度路径，但仍不声称任意密度函数或所有机制组合都已验证。

## W6：双 nubar 裂变核被无补偿混用（已修复）

### 物理对象与正确关系

多群裂变伴随核依赖 $\nu\Sigma_f$ 与谱 $\chi$：

$$F^\dagger(h\to g)=\chi(h)\nu\Sigma_f(g).$$

prompt nubar 与 total nubar 描述不同物理定义。究竟采用哪一个是模型选择；但初始化裂变总量、裂变概率、前驱群抽样和权重必须基于**同一个**选择。

### 修复前偏差与结果影响

当 `NNUBAR>1`，RMC 初始化和通用 getter 使用第二组 nubar；运行时伴随裂变前驱群却硬编码第一组 nubar。两组与 $\Sigma_f$ 相乘后形成不同核，程序没有施加重要性补偿。

这相当于按一张分布确定裂变产生总量，却按另一张分布决定后继属于哪个能群。增加历史不会让这种不一致自动消失；只会更精确地抽到当前实现定义的混合核。

### 数据与验证边界

部署 `c5g7td` 的两组数据确实不同，故修复前不一致成立。该表的概率差很小，V3 的正态近似功效尺度约为 7330 万观测后继；这不是严格样本量保证。修复后 10,000 历史动态重放产生 2,487 条 bank 后继并正常结束，用于证明真实路径可达，不用于分辨微小频数差。随后 `g6↔g1` 裂变主导最终响应以五组独立流运行，全部逐组和合并 $|z|\le3$，合并 $z=-0.703$；该结果仍只覆盖单材料/群对/几何。

### 修复与物理证据

用户已拍板沿用 standard/HDF5 既有的 total 优先语义。运行时前驱群抽样现与初始化和通用 getter 一样通过 total nubar locator；单表时 locator 不变。解析同一部署双表后，初始化与运行时的 $\nu\Sigma_f$ 逐群值、总和及归一化概率完全一致，最大差为 0。该结论修复 standard MGACE 当前路径，不扩展到 delayed、AIS/HDF5 或连续能量。

## W7：纯中子初始化却访问 photon 群

### 物理对象与正确关系

纯中子 MGACE 数据只定义中子能群时，伴随初始化只需要中子上限和中子群结构。不存在 photon 群是合法的核数据状态，不应影响中子伴随计算。

### 修复前偏差与结果影响

RMC 伴随初始化无条件同时定位中子和 photon 最大伴随能量。若数据碰巧带 photon 群，额外访问可只产生无关上限 warning；若数据没有 photon 群，访问空数组会在输运历史开始前崩溃。

V3 的 `c5g7td` 最小输入在第一条 source state 前收到 SIGSEGV，调用栈指向 photon `LocateMgErgGrp()`。这不仅使合法纯中子问题不可运行，也曾阻断 W6 的动态裂变验证。

### 修复逻辑：只访问本次计算实际存在的粒子群

伴随初始化需要把用户给定的“最大伴随能量”转换成核数据中的能群位置。转换方法本身没有问题；错误在于旧逻辑默认 neutron 群和 photon 群一定同时存在，因而无论本次计算追踪什么粒子，都连续执行两次转换。

修复后采用两层判断：

1. 只有启用伴随计算时，才处理伴随能量上限。
2. 在伴随计算内部，neutron 与 photon 分别判断：运行模式包含 neutron 才访问 neutron 群结构，包含 photon 才访问 photon 群结构。

| 本次运行包含的粒子 | 定位 neutron 上限 | 定位 photon 上限 |
|---|---:|---:|
| 仅 neutron | 是 | 否 |
| 仅 photon | 否 | 是 |
| neutron + photon（可再含 electron） | 是 | 是 |
| photon + electron | 否 | 是 |

因此，对纯中子问题，逻辑现在等价于：

```text
确认这是伴随计算
	→ 确认运行模式包含 neutron
	→ 用 neutron 群边界定位 neutron 最大伴随能量
	→ 确认运行模式不包含 photon
	→ 跳过 photon 群访问
	→ 继续后续初始化和输运
```

这里的关键不是“为空数组补一个默认 photon 群”，也不是“捕获崩溃后继续”，而是承认纯中子核数据没有 photon 群完全合法，从调用入口消除不应发生的访问。这样既不会掩盖真正的核数据配置错误，也不需要改变底层能群定位函数对合法调用的检查规则。

### 修复没有改变什么

这项修改只决定**是否应访问某类粒子的群结构**。对应粒子确实存在时，最大能量到群号的转换算法、群边界、截面、伴随碰撞核和权重计算均保持原样。因而它恢复的是合法输入的初始化可达性，不是对 W5 密度权重或 W6 裂变核的间接修正，也不能单独证明最终伴随重要性场正确。

### 修复与验证状态

W7 是控制逻辑和数据边界错误，不是输运方程本身的物理模型选择。修复将 neutron 和 photon 上限定位分别限制在实际包含对应粒子的运行模式内，因此 neutron-only 不再访问 photon 群。

同一 `c5g7td` 输入在修复前退出 11、没有 source state；修复后退出 0，完成 10,000 个源历史并记录 12,487 条初始/后继粒子状态。既有 H/O 伴随回归 1/1 通过，reference 哈希不变。该结果确认 W7 的启动崩溃已消除，但不验证 W5/W6，也不等于裂变伴随物理已经正确。

## W9：负单变量伴随角核使用错误区间宽度（已修复）

### 物理对象与正确关系

MGACE 单变量角表示的表值 $x$ 是散射余弦的目标均值，不是区间端点。对 $x<0$，均匀分布应位于

$$\mu\in[-1,1+2x],$$

因此可写为 $\mu=-1+2\xi(1+x)$。例如 $x=-0.5$ 时，正确支持域是 `[-1,0]`，均值仍为 `-0.5`。

### 当前偏差与结果影响

前向分支使用正确的 $1+x$，伴随分支却使用 $1-x$。对 $x=-0.5$，后者在方向更新前给出 `[-1,2]`，不仅改变均值，还会产生物理余弦范围外的值。后续状态更新会把方向向量归一化，因此“最终方向模等于 1”不能证明角抽样正确；错误方向仍会改变后续自由飞行、边界穿越与 tally。

### 动态证据与门禁

任务 11 的私有一群、纯自散射 MGACE 已由独立 oracle 读回 NXS/JXS/XSS、locator、P0、支持域、矩和哈希。低光学厚度正式对照采用 100000 histories/mode、seed 17：前向真实碰撞 PTRAC 校准的射线交会重建器假阳性为 0、漏检为 1；前向 `0/509` 越界，伴随 `161/330` 越界，伴随最大余弦约 `0.994`。多碰撞历史期望上界约 4.963，出现至少 161 条的 Chernoff 概率上界小于 $10^{-175.52}$。

这满足标准路径可达、数学后果明确和动态反例三项条件，因此修复前完整能力为 E。用户拍板后，伴随 neutron 负分支已改为与前向相同的 $1+x$。三个独立 seed 共 1438 对修复后样本前/伴随逐项一致、零越界，合并均值 $z=0.367$；既有 CTest、reference 与五类资产 oracle 均通过。

同一数学错误后来又在普通伴随 photon 与 photon→neutron 次级条件角核中经生产函数返回值直接确认：修复前各 200 样本分别有 130 和 144 个越过正确上界 0。两处逐路径改为 $1+x$ 后，又用无单群定位退化的两群资格资产复验：两路径三 seed 的 6/6 整程和 9/9 生产采样日志均零 Warning/零 Error；每条路径各 900 样本均零越界且均值与 $-0.5$ 相容，普通 photon 900 个正向/伴随样本逐项一致。旧一群整程的 401/402 条能群下界 warning 已保留，但不再作为干净成功证据。这里验证的是两个特定条件角核，不是对完整 photon 输运、耦合反应率或最终响应互易性的放行。

## 为什么局部 V4 通过不矛盾

V4 使用 $r=1$、非裂变 H/O、带 photon 群数据和未触发 W9 的 P0 角核，分别避开了 W5、W6、W7、W9 的主要触发条件。因此两个群对当时未检测到显著差异，与修复前完整能力 E — Defect 完全可以同时成立。当前四项缺陷及后续角表示、density mesh、NNUBAR=1/混合材料门槛均已闭合；最终有界 A 依赖全部证据矩阵，而不是单靠 V4。
